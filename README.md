## ภาพรวมโปรแกรม

`My Bill Analyzer` เป็นเว็บแอปแบบไฟล์ HTML เดี่ยว สำหรับอัปโหลดสลิปชำระเงินหรือสลิปโอนเงินทั่วไปจากมือถือ แล้วอ่านข้อมูลด้วย OCR เพื่อนำมาวิเคราะห์ค่าใช้จ่าย เช่น ยอดเงิน ผู้รับโอนหรือร้านค้า วันที่ทำรายการ หมวดค่าใช้จ่าย และธนาคารที่เกี่ยวข้อง

โปรแกรมออกแบบให้ใช้งานผ่านเบราว์เซอร์โดยเปิดไฟล์ `Bill_Analyzer_public.html` ได้โดยตรง ไม่ต้องติดตั้งเซิร์ฟเวอร์เพิ่มเติม ข้อมูลที่อ่านได้จะถูกเก็บไว้ในเบราว์เซอร์ของเครื่องที่ใช้งาน

## รูปแบบไฟล์ที่รองรับ

โปรแกรมรองรับการอัปโหลดไฟล์ต่อไปนี้

- รูปภาพ: `.jpg`, `.jpeg`, `.png`, `.webp`, `.bmp`, `.gif`
- เอกสาร: `.pdf`
- ไฟล์รวมหลายสลิป: `.zip`

กรณีอัปโหลด `.zip` โปรแกรมจะค้นหาไฟล์รูปภาพหรือ PDF ภายใน zip แล้วอ่านทีละรายการ

## การทำงานของกราฟภาพรวมค่าใช้จ่าย

กราฟในหน้า `ภาพรวม` มีเงื่อนไขการแสดงผลดังนี้

- ถ้าข้อมูลในช่วงที่เลือกไม่เกิน 12 เดือน จะแสดงเป็นกราฟรายเดือน
- ถ้าข้อมูลมากกว่า 12 เดือน จะแสดงเป็นกราฟรายปี
- เมื่อคลิกแท่งของปีใด โปรแกรมจะแสดงข้อมูลย่อยรายเดือนทั้ง 12 เดือนของปีนั้น
- ในมุมมองรายเดือนของปี จะมีปุ่ม `กลับรายปี` เพื่อกลับไปดูภาพรวมรายปี

## ลำดับการทำงานของระบบ

1. ผู้ใช้อัปโหลดไฟล์ผ่านปุ่ม `อัปโหลดสลิป` หรือวางไฟล์ลงบนหน้าจอ
2. โปรแกรมแยกรายการไฟล์ที่รองรับจากรูปภาพ, PDF หรือ ZIP
3. โปรแกรมสร้างภาพตัวอย่างของสลิปเพื่อใช้ตรวจสอบภายหลัง
4. OCR อ่านข้อความจากสลิปด้วยภาษาไทยและอังกฤษ
5. โปรแกรมแยกข้อมูลสำคัญจากข้อความ OCR
6. โปรแกรมตรวจรายการซ้ำ
7. โปรแกรมบันทึกข้อมูลลง IndexedDB ในเบราว์เซอร์
8. หน้าจอวิเคราะห์ทั้งหมดถูกคำนวณใหม่และแสดงผลอัตโนมัติ

## ระบบ OCR

ระบบ OCR ใช้ `Tesseract.js` เพื่ออ่านข้อความจากรูปหรือหน้าแรกของ PDF โดยตั้งค่าภาษาเป็น

- `tha` สำหรับภาษาไทย
- `eng` สำหรับภาษาอังกฤษ

ข้อมูลที่พยายามอ่านจากสลิป ได้แก่

- จำนวนเงิน
- ผู้รับโอนหรือร้านค้า
- วันที่ทำรายการ
- รหัสอ้างอิงหรือรหัสธุรกรรม
- ธนาคาร
- ข้อความ OCR เต็มของสลิป

หาก OCR อ่านยอดเงิน ผู้รับโอน หรือรหัสอ้างอิงได้ไม่ครบ โปรแกรมจะกำหนดรายการนั้นเป็น `ต้องตรวจสอบ`

## การตรวจรายการซ้ำ

โปรแกรมป้องกันการอัปโหลดสลิปซ้ำโดยสร้างตัวตนของสลิปจากข้อมูลตามลำดับนี้

1. รหัสอ้างอิง (`ref`) ถ้ามี
2. ข้อความ OCR เต็มของสลิป
3. ข้อความดิบหรือข้อมูลสำรอง
4. วันที่ ยอดเงิน และชื่อผู้รับโอน สำหรับรายการที่กรอกเอง

ถ้าพบรายการเดิม และรายการเดิมยังอ่านข้อมูลไม่ครบ แต่ไฟล์ใหม่อ่านยอดเงินได้ โปรแกรมจะอัปเดตรายการเดิมแทนการเพิ่มซ้ำ

## รายการที่ควรตรวจสอบและการแก้ไข Manual

หน้า `รายการที่ควรตรวจสอบ` ใช้สำหรับตรวจรายการที่ OCR ยังอ่านไม่ครบหรือมีความเสี่ยง เช่น

- ไม่พบยอดเงิน
- ไม่พบผู้รับโอนหรือชื่อร้านค้า
- ไม่พบรหัสอ้างอิง
- ข้อมูลดูไม่ชัดเจนจาก OCR

ผู้ใช้สามารถคลิกรายการเพื่อเปิดหน้าต่างแก้ไข โดยจะแสดงภาพสลิปประกอบและฟอร์ม Manual สำหรับแก้ข้อมูลเฉพาะรายการนั้น

ข้อมูลที่แก้ไขได้ ได้แก่

- วันที่ทำรายการ
- จำนวนเงิน
- ผู้รับโอนหรือร้านค้า
- หมวดค่าใช้จ่าย
- ธนาคาร
- ช่องทางข้อมูล
- รหัสอ้างอิง
- หมายเหตุ
- สถานะต้องตรวจสอบ

เมื่อบันทึก Manual โปรแกรมจะอัปเดตเฉพาะรายการนั้น และคำนวณกราฟ/ตารางใหม่ทันที

| โอนเงิน/พร้อมเพย์ | โอนเข้าบุคคลหรือบัญชีทั่วไป |

| `date` | วันที่และเวลาทำรายการ |
| `period` | เดือนของรายการ รูปแบบ `YYYY-MM` |
| `month` | เดือนแบบตัวเลข |

| `source` | ชื่อไฟล์ต้นทาง |

| `manualEdited` | ระบุว่าเคยแก้ไข Manual หรือไม่ |
| `manualUpdatedAt` | วันเวลาที่แก้ไข Manual ล่าสุด |

## จุดที่เก็บข้อมูล

โปรแกรมเก็บข้อมูลไว้ใน IndexedDB ของเบราว์เซอร์เครื่องนั้น

| รายการ | ค่า |
|---|---|
| Database name | `my_bill_analyzer` |
| Object store | `slips` |
| Key path | `key` |
| Settings key | `__settings` |

ข้อมูลไม่ได้ถูกบันทึกเป็นไฟล์แยกอัตโนมัติ และไม่ได้ส่งออกไปยังเซิร์ฟเวอร์ภายนอก การล้างข้อมูลเบราว์เซอร์หรือ IndexedDB ของเว็บไซต์นี้อาจทำให้ข้อมูลสลิปที่เคยอัปโหลดหายไป

## โครงสร้างฟังก์ชันสำคัญในโปรแกรม

| กลุ่ม | ฟังก์ชันหลัก | หน้าที่ |
|---|---|---|
| เตรียมข้อมูล | `normalizeRecord()` | จัดรูปแบบข้อมูลสลิปให้เป็นมาตรฐาน |
| สร้างรหัสรายการ | `makeKey()`, `slipIdentity()` | สร้าง key และตรวจรายการซ้ำ |
| สร้างชุดข้อมูลวิเคราะห์ | `rebuildData()`, `computeView()` | รวมข้อมูลตามเดือน ร้านค้า หมวด และช่วงเวลา |
| OCR | `ocrSlipBlob()`, `ocrCanvas()` | อ่านข้อความจากรูปภาพหรือ PDF |
| แยกข้อมูล OCR | `parseSlipAmount()`, `parseSlipPayee()`, `parseSlipRef()`, `parseSlipDate()` | แยกยอดเงิน ผู้รับโอน รหัสอ้างอิง และวันที่ |
| อัปโหลดไฟล์ | `collectSlipFiles()`, `handleFiles()` | รับไฟล์ แยก ZIP อ่าน OCR และบันทึกข้อมูล |
| บันทึกข้อมูล | `idbOpen()`, `idbPut()`, `idbAll()`, `idbClear()` | จัดการ IndexedDB |
| Manual review | `renderWatch()`, `openReviewEditor()`, `saveManualReview()` | เปิดดูสลิปและแก้ไขข้อมูลรายรายการ |
| กราฟภาพรวม | `renderBars()`, `yearlyChartItems()`, `drillMonthItems()` | แสดงกราฟรายเดือน/รายปี และเจาะดูรายเดือน |
| ตารางและกราฟอื่น | `renderHeatmap()`, `renderStacked()`, `renderInsights()`, `renderStructure()`, `renderBanks()` | แสดงผลวิเคราะห์แต่ละหน้า |
| ตั้งค่า | `applyTheme()`, `applyAccent()`, `saveSettings()`, `loadSettings()` | จัดการธีม สี และการตั้งค่า |

## วิธีใช้งาน

1. เปิดไฟล์ `Bill_Analyzer_public.html` ด้วยเบราว์เซอร์ เช่น Chrome หรือ Edge
2. กดปุ่ม `อัปโหลดสลิป`
3. เลือกรูปสลิป, PDF หรือ ZIP ที่ต้องการนำเข้า
4. รอให้ OCR อ่านข้อมูลจนจบ
5. ดูผลในหน้า `ภาพรวม`
6. เข้าเมนู `รายการที่ควรตรวจสอบ` เพื่อแก้ไขรายการที่ OCR อ่านไม่ครบ
7. ใช้เมนู `แยกตามธนาคาร`, `โครงสร้างค่าใช้จ่าย`, และ `ตารางความหนาแน่น` เพื่อวิเคราะห์เพิ่มเติม

## ข้อควรระวัง

- OCR อาจอ่านผิดได้หากรูปไม่ชัด เบลอ แสงน้อย หรือมีตัวหนังสือเล็กมาก
- PDF จะอ่านจากหน้าแรกของเอกสาร
- ข้อมูลถูกเก็บในเบราว์เซอร์ของเครื่องที่ใช้งาน ไม่ได้ซิงก์ข้ามเครื่อง
- หากย้ายไปใช้เครื่องอื่น ต้องอัปโหลดข้อมูลใหม่
- หากเบราว์เซอร์บล็อกสคริปต์จาก CDN อาจทำให้ OCR ใช้งานไม่ได้
