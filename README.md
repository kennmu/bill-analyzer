# AIS Bill Analyzer · วิเคราะห์ใบแจ้งค่าบริการ AIS

แดชบอร์ดวิเคราะห์ค่าใช้จ่ายโทรศัพท์มือถือจากใบแจ้งค่าบริการ AIS ช่วยสรุปภาพรวมรายเดือน เปรียบเทียบรายหมายเลข และวิเคราะห์สาเหตุค่าใช้จ่ายที่เพิ่มขึ้น เพื่อการบริหารและตัดสินใจปรับแพ็กเกจ

เพียงอัปโหลดใบแจ้งหนี้ (ไฟล์ PDF) ของ AIS ระบบจะอ่านข้อมูล สรุปยอด แยกหมวดค่าใช้จ่าย และชี้จุดที่ควรตรวจสอบให้โดยอัตโนมัติ — ทำงานได้ทั้งหมดในเครื่องของผู้ใช้ ไม่มีการส่งข้อมูลออกไปที่ใด

---

## คุณสมบัติเด่น

- **อ่านใบแจ้งหนี้อัตโนมัติ** — รองรับไฟล์ PDF ของ AIS โดยตรง อัปโหลดทีละไฟล์ หลายไฟล์ หรือไฟล์ ZIP รวมทั้งเดือนได้
- **สรุปหลายมุมมอง** — ภาพรวมรายเดือน, ตารางความหนาแน่น, สัดส่วนรายหมายเลข, โครงสร้างค่าใช้จ่าย และรายการที่ควรตรวจสอบ
- **วิเคราะห์สาเหตุ** — ระบุว่าค่าใช้จ่ายที่เพิ่มขึ้นเกิดจากอะไร เช่น แพ็กเกจโรมมิ่ง การโทรเกิน หรือการใช้เน็ตเพิ่ม พร้อมตัวเลขเปรียบเทียบกับเดือนก่อน
- **ทำงานในเครื่อง (Offline)** — ไลบรารีฝังอยู่ในไฟล์ ไม่ต้องเชื่อมต่ออินเทอร์เน็ตขณะใช้งาน และข้อมูลไม่ถูกส่งออกไปที่เซิร์ฟเวอร์ใด
- **จดจำข้อมูล** — ข้อมูลที่อัปโหลดถูกบันทึกในเครื่องของผู้ใช้ ปิดแล้วเปิดใหม่ข้อมูลยังอยู่ จนกว่าจะกดล้างข้อมูล
- **ปรับแต่งหน้าตา** — เลือกชุดสีได้ 5 แบบ และสลับโหมดสว่าง/มืดได้

## เริ่มต้นใช้งาน

### 1. เปิดไฟล์ให้ถูกวิธี

โปรแกรมนี้เป็นไฟล์ HTML ไฟล์เดียว ทำงานในเว็บเบราว์เซอร์ (เช่น Google Chrome, Microsoft Edge, Safari)

- **ดาวน์โหลดไฟล์ลงเครื่องก่อน** แล้วดับเบิลคลิกเปิด — วิธีนี้ใช้งานได้ครบทุกฟังก์ชัน
- แนะนำให้ใช้ **Google Chrome** หรือ **Microsoft Edge** บนคอมพิวเตอร์ จะเสถียรที่สุด

> ⚠️ อย่าเปิดไฟล์ผ่านหน้าพรีวิวของ Google Drive โดยตรง เพราะ Google Drive ไม่ได้รันโปรแกรม HTML ต้องกดดาวน์โหลดลงเครื่องก่อนทุกครั้ง

### 2. ทำความรู้จักหน้าจอ

เมื่อเปิดมาครั้งแรก จะเห็น **ข้อมูลตัวอย่าง 4 หมายเลข** ให้ลองใช้งานดูก่อนได้ (ไม่ใช่ข้อมูลจริง)

- **แถบซ้าย (เมนู):** สลับดูหน้าต่าง ๆ ของแดชบอร์ด
- **มุมขวาบน:** เลือกช่วงเดือน (รอบบิล) และปุ่มสลับโหมดสว่าง/มืด
- **ตรงกลาง:** เนื้อหาของแต่ละหน้า เปลี่ยนตามเมนูที่เลือก

### 3. นำข้อมูลจริงเข้า — อัปโหลดใบแจ้งหนี้

กดปุ่ม **"อัปโหลดใบแจ้งหนี้ AIS"** ที่แถบซ้าย แล้วเลือกไฟล์ใบแจ้งหนี้ AIS (ไฟล์ PDF)

- เลือกได้ทั้ง **ทีละไฟล์**, **หลายไฟล์พร้อมกัน**, หรือ **ไฟล์ ZIP** ที่รวมทั้งเดือน
- จะลากไฟล์มาวางบนหน้าจอก็ได้
- โปรแกรมจะอ่านเอง รู้เองว่าเป็นเดือนอะไร หมายเลขอะไร แล้วคำนวณให้อัตโนมัติ

### 4. รูปแบบไฟล์ที่ระบบรองรับ

ใบแจ้งหนี้ AIS 1 ใบ = 1 หมายเลข = 2 หน้าเสมอ (เป็นรูปแบบมาตรฐานของ AIS) ระบบอ่านข้อมูลจากหน้าที่ 2

- ถ้าอัปโหลดเดือนที่เคยมีแล้ว ระบบจะ **เขียนทับด้วยข้อมูลใหม่**
- ถ้าไฟล์ไม่ใช่ 2 หน้า ระบบจะข้ามไฟล์นั้นและแจ้งเตือน

## คำอธิบายแต่ละเมนู

| เมนู | ใช้ดูอะไร |
|------|-----------|
| **ภาพรวม** | สรุปภาพใหญ่ทั้งหมด — ยอดรวมทุกเดือน ค่าเฉลี่ยต่อเดือน เดือนที่ใช้สูงสุด และกราฟแท่งเทียบรายเดือน |
| **ตารางความหนาแน่น** | ตารางสีรายหมายเลข × รายเดือน สียิ่งเข้มยิ่งค่าใช้จ่ายสูง เรียงลำดับและค้นหาได้ |
| **สัดส่วนรายเบอร์** | กราฟแท่งยอดรวมของแต่ละหมายเลข เรียงจากมากไปน้อย แบ่งสีตามเดือน |
| **ข้อสังเกตสำคัญ** | สรุปประเด็นเด่นแบบกราฟ — การกระจุกตัวของค่าใช้จ่าย หมายเลขอันดับ 1 และการเปลี่ยนแปลงที่ชัดเจน |
| **โครงสร้างค่าใช้จ่าย** | แตกยอดบิลเป็นหมวด (ค่าแพ็กเกจ / ส่วนเกิน / SMS / VAT) พร้อมข้อมูลการใช้งานจริง (นาทีโทร, เน็ต) |
| **รายการที่ควรตรวจสอบ** | คัดเฉพาะหมายเลขที่มีค่าส่วนเกินหรือยอดพุ่งผิดปกติ พร้อมระบุสาเหตุจริงและตัวเลขเปรียบเทียบ |
| **คู่มือวิธีใช้** | คำแนะนำการใช้งานทีละขั้นสำหรับผู้เริ่มต้น |
| **ตั้งค่า** | เลือกชุดสี 5 แบบ และสลับโหมดสว่าง/มืด |

> 💡 ทุกหน้าจะคำนวณตาม **ช่วงรอบบิล** ที่เลือกไว้มุมขวาบน เช่น ถ้าเลือกแค่ มี.ค.–เม.ย. ตัวเลขทุกหน้าจะแสดงเฉพาะ 2 เดือนนั้น

## การบันทึกข้อมูล

เมื่ออัปโหลดข้อมูลแล้ว ระบบจะ **จดจำไว้ในเครื่องของผู้ใช้** (ผ่าน IndexedDB ของเบราว์เซอร์) ปิดไฟล์หรือปิดเบราว์เซอร์แล้วเปิดใหม่ ข้อมูลยังอยู่ จนกว่าจะกดปุ่ม "ล้างข้อมูล / เริ่มใหม่"

- ข้อมูลผูกกับ **เครื่องและเบราว์เซอร์เดิม** รวมถึงตำแหน่งไฟล์เดิม
- หากย้ายไฟล์ไปโฟลเดอร์อื่น เปลี่ยนเบราว์เซอร์ หรือเปิดบนเครื่องอื่น ระบบจะเริ่มนับใหม่ (ข้อมูลเดิมไม่หาย แต่จะอยู่คนละที่)
- เพื่อความต่อเนื่อง แนะนำให้เก็บไฟล์ไว้ที่เดิมและเปิดที่เดิมเสมอ

## ความเป็นส่วนตัว

โปรแกรมทำงานทั้งหมดภายในเบราว์เซอร์ของผู้ใช้ ข้อมูลใบแจ้งหนี้ที่อัปโหลด **ไม่ถูกส่งออกไปยังเซิร์ฟเวอร์ใด ๆ** และถูกเก็บไว้ในเครื่องของผู้ใช้เท่านั้น ข้อมูลจะไม่ติดไปกับไฟล์เมื่อส่งต่อ เพราะเก็บอยู่ในเบราว์เซอร์ ไม่ได้อยู่ในไฟล์ HTML

## ข้อกำหนดทางเทคนิค

- เว็บเบราว์เซอร์รุ่นใหม่ (แนะนำ Google Chrome หรือ Microsoft Edge)
- ไม่ต้องติดตั้งโปรแกรมเพิ่ม ไม่ต้องเชื่อมต่ออินเทอร์เน็ตขณะใช้งาน
- ไฟล์เดียวจบ (ไลบรารีอ่าน PDF และจัดการไฟล์ ZIP ฝังอยู่ในไฟล์แล้ว)
